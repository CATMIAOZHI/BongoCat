## 功能

- 键盘、鼠标和手柄驱动猫咪动作，支持自定义模型。
- 双人联机显示对方猫、按键高亮、输入统计和暂离状态。
- 文字聊天与语音录制、试听、确认发送。
- 自建中继、P2P 直连和中继回退；也可以完全不用服务器，用「配对码」把两段码自己转送给对方。配对内容端到端加密。
- 自动选择本地已有的对方模型，不传输模型文件；找不到时使用自己的模型并提示。
- 单人模式可离线使用。除了你自己填写的联机服务器，以及「配对码」模式下可以在设置里换的那几个公开 STUN，不向任何第三方上报数据。

## 模型

在「偏好设置 → 模型」导入兼容的模型文件夹。

联机自动同步只发送模型名称和类型，不包含本机路径或模型文件。自定义模型必须由双方自行放到本地并导入，且模型名称保持一致。新导入默认保留原文件夹名称；旧模型可以点模型卡片上的铅笔补填名称，无需重新导入。名称相同但内容不同的模型无法仅凭名称区分，请使用不同的名称；多份同名模型会回退到自己的模型。

「双人联机 → 对方猫 → 自动同步对方模型」默认开启；关闭后可手动选择。旧版客户端不提供模型信息时使用自己的模型。两端升级后才能互相同步。

## 服务器部署

- [自建服务器（推荐，支持多个双人会话）](server-relay/README.md)
- [Cloudflare 中继](server-cloudflare/README.md)

客户端填写服务器地址、服务器密码和配对密码。服务器密码由部署者设置，配对密码由一对用户共同使用。

不想部署服务器也不用公开中继时，可以用「双人联机 → 配对码」：两台电脑各出一段码，互相发过去就能连上，全程不经过任何服务器。代价是连上之前聊天 / 附件 / 语音都不可用，换了网络要重新发一次码；打洞用的 STUN 可以在那一栏里换成你自己的。

## 更新

应用只检查本仓库的正式客户端 Release。发现新版本后打开下载页，由用户选择安装包并安装；自用包不签名，不执行静默覆盖安装。`relay-v*` 是服务器版本，不会作为客户端更新。
